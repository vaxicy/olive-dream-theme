## 预览图生成 + README 徽章
- 用 **Node.js + 纯 zlib PNG 编码**（`scripts/gen_preview.js`）成功生成浅色/深色预览图（960x600，内置 6x10 位图字体，零依赖）。
- PowerShell GDI+ 方案（`scripts/gen_preview.ps1`）在此环境下**复杂渲染会超时挂死**（最小测试能过但大画布+大量 DrawString 不行）；根因：PowerShell 进程在处理大量 GDI+ 对象时卡住。通过 `cmd /c` 中转可解决简单调用但不解决性能问题。
- PS1 脚本踩过的坑：
  - `[Parameter(Mandatory=$true)]` 命名参数绑定异常 → 改用 `$args[0]` 位置参数
  - 函数名 `Sc` 与 PowerShell 别名 `sc`(Set-Content) 冲突 → 改名 `TokColor`
  - `DrawLine` 的 x2/y2 坐标误写为 `1`（4 处）→ 导致对角线贯穿画布
  - `System.Drawing.Text` 程序集不可用 → 删除引用和 TextRenderingHint
