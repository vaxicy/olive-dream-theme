# Changelog

## [1.1.0] - 2026-07-28

### Added
- **Olive Dream Dark** variant — deep olive‑charcoal background (`#21271A`) with the same calm natural palette, registered as a second theme.
- Both variants now appear in the Color Theme picker: `Olive Dream` (light) and `Olive Dream Dark`.

## [1.0.0] - 2026-07-28

### Added
- Initial release of **Olive Dream Theme**
- Soft cream‑green editor background (`#F8F6EA`)
- Cohesive sage / olive workbench palette (Activity Bar, Side Bar, Panel, Status Bar)
- Calm syntax highlighting tuned for JS, TS, React, HTML, CSS, JSON and Python
- Semantic highlighting support
- Natural terminal ANSI color set
- Premium minimal icon (olive circle + white leaf)
